## Phase 11: Bug Fixes & UI Improvements
> **Goal:** Fix immediate state management bugs and refine UI elements.
> **Priority:** P0

- [ ] **Fix Play Page State Updates:** Ensure Level, XP, and Day Streak update immediately upon returning to the Play page.
- [ ] **Fix Light Theme Report Card:** Correct the UI on the results/report card screen in light theme where elements are breaking out of the center circle.
- [ ] **Auto-Go on Correct Answer:** Implement a feature to automatically proceed to the next question when the correct answer is entered, instead of requiring a button click.
- [ ] **Highlight Rectangle UI Polish:** Modify the correct/wrong answer highlight rectangle. Change it from a vertical rectangle to a horizontal rectangle that appears only over the answer text, making it cleaner.
